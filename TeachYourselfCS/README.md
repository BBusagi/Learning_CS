# TeachYourselfCS

计算机基础自学路线与学习笔记，当前整理了 Crafting Interpreters 和 Coding Adventure 的内容。

## 学习路线

按现有[自学计划](ReadMe.txt)安排：

1. Crafting Interpreters：通过解释器与虚拟机练习，理解语言实现。
2. Computer Architecture：学习计算机体系结构，建立性能与优化相关的基础。
3. 操作系统：逐步阅读操作系统教材。
4. Sebastian Lague / Coding Adventure：作为计算机原理与图形直觉的补充。
