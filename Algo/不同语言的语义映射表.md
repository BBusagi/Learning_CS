# 不同语言的语义映射表

按需求对照 Python 与 C# 的常用写法，供算法题解跳转查阅。Python API 的详细说明见 [Python 常用语法](../Python/常用语法.md)。

## 找最值

- Python：`min(...)` / `max(...)`，或在遍历中维护当前最优值。详见 [找最值](../Python/常用语法.md#找最值)。
- C#：`Enumerable.Min(...)` / `Enumerable.Max(...)`，或使用循环维护当前最优值。

## 反转后拼接

- Python：`''.join(reversed(parts))` 或先 `parts.reverse()` 再 `''.join(parts)`。详见 [字符处理](../Python/常用语法.md#字符处理)与[反转 API](../Python/常用语法.md#反转-api)。
- C#：可使用 `Array.Reverse(...)` 后再 `string.Join(...)`，或通过 `StringBuilder` 拼接。

## 空格处理

- Python：`s.strip()`、`s.split()`、`' '.join(parts)`。详见 [字符处理](../Python/常用语法.md#字符处理)。
- C#：`s.Trim()`、`s.Split(...)`、`string.Join(...)`。

## 整数范围

- Python：`int` 没有固定上限。
- C#：`int` 是固定宽度的整数类型，取值范围有限。

## 元组
- Python 的 `tuple` 更像“轻量、不可变记录”
- 对照 C# 时，可以先类比 `ValueTuple`
- 但不完全等价：Python `tuple` 强调不可变，C# `ValueTuple` 是值类型

## 方法定义
```csharp
private int Function(int x)
{
    return 100;
}
```

```python
# Python 是动态类型
def function(x):
    return 100

# 类型注解只提供提示，不会默认强制校验
def function(x: int) -> int:
    return 100
```

## 访问修饰符
- C#: `public / protected / private / internal`
- Python 没有真正强制的访问修饰符，更多是约定
- `name`: 公共成员
- `_name`: 约定为“内部使用”
- `__name`: 触发 name mangling，不等于真正的 private

## 优先级队列
- Python：使用 `heapq`，默认是最小堆。调用示例、最大堆写法和排序规则见 [数据结构：优先级队列](../Python/常用语法.md#数据结构优先级队列)。
- C#：使用 `PriorityQueue<TElement, TPriority>`，调用示例如下。

```csharp
var pq = new PriorityQueue<TElement, TPriority>();

// 插入
pq.Enqueue(element, priority);

// 弹出优先级最高（默认是最小 priority）
pq.Dequeue();

// 查看队首
pq.Peek();

// 元素数量
pq.Count;

// 安全弹出
pq.TryDequeue(out var element, out var priority);
```
